# Reference

## Controls

| Key | Action |
|---|---|
| **K** | Opens the quest book |
| **G** | Shows or hides each quest's steps in the HUD |

## Client configuration

File `config/questmod-client.toml`.

| Option | Default | Description |
|---|---|---|
| `hud.enabled` | `true` | Shows the progress of active quests on screen |
| `hud.side` | `LEFT` | HUD side: `LEFT` or `RIGHT` |
| `hud.maxQuests` | `5` | Maximum quests shown in the HUD (1 to 10) |
| `hud.expanded` | `false` | Shows each quest's steps separately (toggled with the **G** key) |
| `npc.allowUrlSkins` | `true` | Allows downloading skins from https links set on NPCs by the server |
| `npc.showNpcMarker` | `true` | Shows the `!` above NPCs |

## Server configuration

File `serverconfig/questmod-server.toml` of each world (or `defaultconfigs/questmod-server.toml` to set values in a modpack).

| Option | Default | Description |
|---|---|---|
| `general.adminPermissionLevel` | `2` | Op level needed to manage quests and NPCs (0 to 4) |
| `general.singleplayerOwnerIsAdmin` | `true` | In a singleplayer world, the owner is an admin even without cheats |
| `general.bookEnabled` | `true` | Enables the quest book (key and item) |
| `general.giveBook` | `FIRST_JOIN` | When the book is given: `NEVER`, `FIRST_JOIN` (once per player) or `IF_MISSING` (on every join, if not carrying one) |

## Commands

For admins (the configured level, 2 by default; the console and command blocks use that same level).

| Command | What it does |
|---|---|
| `/questmod export <namespace>` | Exports the world's quests and sections as a datapack in `questmod_export/<namespace>/` |
| `/questmod reset <players> [quest]` | Resets all progress, or a single quest |
| `/questmod complete <players> <quest>` | Marks a quest as completed |
| `/questmod community reset <quest>` | Resets a community quest for everyone (counter, contributions and claimed rewards) |

Use the usual `/reload` to reload datapack quests.

## Items and entities

| ID | What it is |
|---|---|
| `questmod:quest_npc` | The Quest Master (`/summon questmod:quest_npc`) |
| `questmod:quest_npc_spawn_egg` | Its spawn egg |
| `questmod:quest_scroll` | Quest scroll (copies and pastes lists between NPCs) |
| `questmod:quest_book` | Quest book (opens the panel without an NPC) |

## Datapack paths

| Path | Content |
|---|---|
| `data/<ns>/questmod/quests/*.json` | Quests |
| `data/<ns>/questmod/sections/*.json` | Sections |

The formats are in [Modpacks and datapacks](modpacks.md) and there are JSON schemas to validate them.
